Intelligent Diagnostics for Preventive Healthcare
Traditional diagnosis relies on lab tests and in-person appointments — allowing diseases to progress undetected. This AI system uses a 6-model ensemble trained on real patient symptom data to predict 120+ diseases at the earliest stage.

Drawing upon a Kaggle dataset of 4,920 records with 132 symptom features, our enhanced ensemble includes Random Forest, SVM, KNN, Gradient Boosting, Logistic Regression and Naive Bayes — achieving 97.4% accuracy with precise musculoskeletal and orthopaedic differentiation.
